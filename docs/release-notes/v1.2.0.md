# musicdl 1.2.0

## English

- The Vue-based control panel gives music search, source and Bot management, runtime settings, and download history a consistent music-focused interface while preserving source import, diagnostics, service logs, channel metrics, and existing account and configuration workflows.
- A single `compose.yaml` now supports quick installation and source builds, starting the application, isolated plugin runner, and private persistent bundled Redis together.
- Quick installation now defaults to the `1.2.0` image pair; the `1.1.5` pair remains available for rollback.

## 中文

- Vue 管理面板为音乐搜索、音源与 Bot 管理、运行配置和下载历史提供统一的音乐主题界面，同时保留音源导入、诊断、服务日志、渠道指标以及现有账号和配置流程。
- 现在可通过单一的 `compose.yaml` 快速安装或从源码构建，并一同启动主服务、隔离的插件运行器和私有持久化 Redis。
- 快速安装现在默认使用 `1.2.0` 镜像对；`1.1.5` 镜像对仍可用于回滚。
