# musicdl 1.1.3

## English

- In musicdl 1.1.3, paste a single source-list link into Sources → Import source to expand its entries into the import queue. The README includes an aggregate link for the twelve community source scripts, whose original filenames and contents are preserved.
- Each listed script is fetched and analyzed separately. Review each source's requested permissions and confirm installation; a failed source does not discard successful previews. Existing local-file and direct-script URL imports remain supported.
- Source lists are bounded by the existing twenty-item queue. List entries use HTTPS, nested lists are rejected, and script requests retain the existing DNS, redirect, timeout, and size protections.
- The quick-install manifest and deployment examples select the `1.1.3` image pair. Upgrade the application to use single-link source-list imports; the `1.1.2` image pair remains available for rollback.

## 中文

- musicdl 1.1.3 支持在「音源 → 导入音源」中粘贴一个音源清单链接，自动将清单中的音源加入导入队列。README 提供十二个社区音源的聚合链接，保留各脚本的原文件名和内容。
- 清单中的脚本分别获取和分析，请检查每个音源的所需权限后确认安装；某个音源失败不会丢弃其他成功的预览。原有本地文件和单脚本 URL 导入继续支持。
- 音源清单受原有二十项队列上限约束，仅接受 HTTPS 条目，拒绝嵌套清单；脚本获取继续执行 DNS、重定向、超时和大小限制。
- 快速安装清单和部署示例选择 `1.1.3` 镜像对。使用单链接清单导入前请升级应用，`1.1.2` 镜像对仍可用于回滚。
