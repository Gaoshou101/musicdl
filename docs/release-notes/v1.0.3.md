# musicdl 1.0.3

## English

- The source management panel supports batch file import and secure URL import for compatible scripts.
- A configured Telegram proxy now reaches Telethon in its supported tuple format. The images include `python-socks`, and unsupported proxy settings or a missing dependency produce an actionable error.
- Main service, plugin runner, and web package versions are synchronized at `1.0.3`.
- Both published images support full deployment and Lite mode. Set `MUSICDL_IMAGE_TAG=1.0.3` to select them; the quick-install manifest was promoted to `1.0.3` after image publication.

## 中文

- 音源管理面板支持批量文件导入，以及对兼容脚本的安全 URL 导入。
- 配置的 Telegram 代理现在会以 Telethon 支持的元组格式生效。镜像包含 `python-socks`；不支持的代理设置或依赖缺失会给出可操作的错误。
- 主服务、插件运行器和 Web 包版本统一为 `1.0.3`。
- 两份已发布镜像均支持完整部署和 Lite 模式。设置 `MUSICDL_IMAGE_TAG=1.0.3` 可选用该版本；快速安装清单在镜像发布后升级为默认使用 `1.0.3`。
