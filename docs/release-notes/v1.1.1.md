# musicdl 1.1.1

## English

- Remembered administrator sign-ins now last 30 days and survive service restarts when the app-data volume is retained. Ordinary browser sessions have a 12-hour server-side expiry; logout and credential changes revoke existing sessions.
- The administration panel now shows timestamped status for the ten latest real search and download requests while keeping the existing search, download, and lossless-quality metrics separate.
- Source diagnostics now offer one-click tests for a single source or all sources, checking search and quality-aware link resolution with bounded workers and deadlines. A resolved link is labeled “Download not yet verified,” and diagnostic probes do not count as real request traffic.
- Panel requests and background workers share a per-process download budget of four active and sixteen waiting jobs, with at most two active jobs per source or user. Bounded local media work improves event-loop responsiveness in a synthetic benchmark; this does not establish production network throughput.
- The quick-install manifest now defaults to the `1.1.1` image pair, and deployment examples pin the same pair. The `1.1.0` pair remains available for rollback.
- The web application no longer includes unused animation dependencies. This cleanup does not claim a smaller bundle or container image.

## 中文

- 管理员的「记住我」登录现在有效 30 天；保留应用数据卷时，服务重启后仍可恢复。普通浏览器会话的服务端有效期为 12 小时；退出登录或修改凭据会撤销已有会话。
- 管理面板现在会显示最近十次真实搜索和下载请求的时间与状态，同时继续分别统计搜索、下载和无损音质指标。
- 音源诊断现在支持一键测试单个音源或批量测试全部音源，在有界 Worker 和超时内检查搜索与按音质解析链接。解析成功会标注「下载尚未验证」，诊断探测不会计入真实请求流量。
- 面板请求和后台任务共享每个进程的下载预算：最多四个进行中、十六个等待中，单个音源或用户最多两个进行中。合成基准测试显示，有界本地媒体处理能改善事件循环响应；这不代表生产网络吞吐量提升。
- 快速安装清单现在默认使用 `1.1.1` 镜像对，部署示例也固定使用同一镜像对；`1.1.0` 镜像对仍可用于回滚。
- Web 应用移除了未使用的动画依赖。此项清理不宣称会缩小前端 bundle 或容器镜像体积。
