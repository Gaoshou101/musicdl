# musicdl 1.0.9

## English

- Search fallback now continues through the available matching sources when one cannot provide a usable track, giving another candidate a chance to complete the download.
- A download is refused when its measured duration disagrees with a trusted catalogue duration.
- Proven corrupt or truncated FLAC streams are rejected, allowing fallback to a valid backup candidate.
- MP3 identification handles false FLAC sync markers and ID3v1 trailers more accurately.
- Files with an unknown suffix remain unverified. Their first 30 bytes alone do not prove corruption, so they are not rejected on that basis.
- Main service, plugin runner, and web package versions are synchronized at `1.0.9`; quick install defaults to the `1.0.9` images, which support full and Lite deployments. To roll back the image version, pin `MUSICDL_IMAGE_TAG=1.0.8` and follow the README backup and migration guidance.

## 中文

- 搜索回退现在会在某个来源无法提供可用曲目时继续尝试其他匹配来源，让其他候选曲目有机会完成下载。
- 文件实测时长与可信的目录时长不一致时，下载会被拒绝。
- 已确认损坏或被截断的 FLAC 音流会被拒绝，并允许回退到有效的备用候选曲目。
- MP3 识别对误判为 FLAC 的同步标记和 ID3v1 尾部标签的处理更加准确。
- 后缀未知的文件仍标记为未验证；仅凭开头 30 个字节无法证明文件损坏，因此不会据此拒绝。
- 主服务、插件运行器和 Web 包版本统一为 `1.0.9`；快速安装默认使用支持完整部署和 Lite 模式的 `1.0.9` 镜像。如需回滚镜像版本，请固定 `MUSICDL_IMAGE_TAG=1.0.8`，并遵循 README 中的备份与迁移说明。
