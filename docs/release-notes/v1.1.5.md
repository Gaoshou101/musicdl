# musicdl 1.1.5

## English

- Download history details now show the latest recorded phase and practical guidance for known failures. The concurrency panel identifies its process-local snapshot, and hides old counts when a refresh fails.
- Adds reproducible search, admission, media, and artifact-size measurements plus an authenticated browser smoke for the panel's login, download-history, source-import, and observability-error flows. These checks establish a baseline and make no performance-improvement claim.
- The quick-install manifest now defaults to the `1.1.5` image pair; the `1.1.4` pair remains available for rollback.

## 中文

- 下载历史详情现在会显示最近记录的阶段，以及已知失败原因的实用处理建议。并发面板会说明计数仅属于当前进程；刷新失败时会隐藏旧计数。
- 增加可复现的搜索、并发等待、媒体和制品体积测量，以及需登录的面板浏览器检查，覆盖登录、下载历史、音源导入和并发状态错误流程。这些检查用于建立基线，不代表性能有所提升。
- 快速安装清单现在默认使用 `1.1.5` 镜像对；`1.1.4` 镜像对仍可用于回滚。
