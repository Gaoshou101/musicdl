- The admin panel now uses a more consistent visual style across search, downloads, sources, bots, configuration, and status pages, with clearer keyboard focus and larger touch targets.
- Contributor checkouts now ignore cloud-drive conflict copies, stray pytest temporary folders, and local GStack state.

- 管理面板的搜索、下载、音源、机器人、配置和状态页面采用了更一致的视觉样式，并提升了键盘焦点提示的清晰度和触屏操作目标的尺寸。
