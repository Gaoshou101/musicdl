# musicdl 1.2.1

## English

- Music search now puts exact song and artist matches ahead of higher-quality mismatches, keeps native catalogue relevance for ambiguous titles, and recognizes explicitly requested Live and other recording versions.
- WeCom search results now use compact title-and-artist cards with duration, advertised quality, and source details. Long names remain identifiable, recording-version labels survive shortening, and page navigation preserves the original selection numbers.
- Quick installation now defaults to the `1.2.1` image pair.

## 中文

- 音乐搜索现在优先展示准确匹配歌名与歌手的结果，避免被音质更高但不匹配的结果挤到后面；同名歌曲保留各平台原有的相关性顺序，并能识别明确指定的 Live 等录音版本。
- 企业微信搜索结果现在采用紧凑的歌名与歌手卡片，并展示时长、标称音质和来源。长名称缩短后仍可辨认，录音版本标记会被保留，翻页时也会保持原有的选曲序号。
- 快速安装现在默认使用 `1.2.1` 镜像对。
