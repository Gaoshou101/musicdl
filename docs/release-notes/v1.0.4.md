# musicdl 1.0.4

## English

- Panel downloads now resolve their language category the same way bot downloads do: deterministic script evidence decides first, and the optional AI advisor can only refine it inside the known categories. A panel download previously reached the media writer with no category at all.
- The console build now copies `web/public` into the export, so the brand icons and the other public assets ship inside the published image instead of 404ing.
- The console's visible brand text now reads `musicdl` instead of `tgmusic`.
- Synchronized main service, plugin runner, and web package versions at `1.0.4`.
- Both published images support the full deployment and Lite mode. Set `MUSICDL_IMAGE_TAG=1.0.4` to use them. The quick-install manifest now defaults to `1.0.4`.
- To roll back the image version, pin `MUSICDL_IMAGE_TAG=1.0.3` and follow the README backup and migration guidance.

## 中文

- 面板下载现在与机器人下载使用同一套语言判定：先由脚本证据确定，可选的 AI 顾问只能在其中细化，不会越出已知分类。此前面板下载到达媒体写入阶段时完全没有分类。
- 控制台构建现在会把 `web/public` 复制进导出产物，品牌图标等公共资源随镜像发布，不再返回 404。
- 控制台可见的品牌文案由 `tgmusic` 改为 `musicdl`。
- 主服务、插件运行器和 Web 包版本统一为 `1.0.4`。
- 两份已发布镜像均支持完整部署和 Lite 模式。设置 `MUSICDL_IMAGE_TAG=1.0.4` 即可使用；快速安装清单现在默认使用 `1.0.4`。
- 如需回滚镜像版本，请固定 `MUSICDL_IMAGE_TAG=1.0.3`，并遵循 README 中的备份与迁移说明。
