# musicdl 1.0.8

## English

- In-flight requests keep their runtime available through a reload, while shutdown waits for reload work to finish and startup failures still release logging resources.
- Catalogue searches retain broker capacity until blocking operations finish. Quality probes bound pending work, and Redis stream workers no longer prefetch tasks they cannot run yet.
- Long WeCom search results now use pages with stable result numbers. Reply `n` or `p` to navigate and `/cancel` to clear the active selection; queued downloads continue, and retried callbacks remain bound to the original search and page.
- Redis retry budgets are now scoped to each consumer group, so one group cannot consume or clear another group's attempts. Dead-letter records retain the group that exhausted its budget.
- Telegram client setup, connection, logout, and shutdown are serialized per profile, preventing concurrent operations from racing over session files.
- Admin updates validate before changing live state and restore the previous state if persistence fails. Session revocation also clears CSRF state, login-rate-limit memory stays bounded, and the service log viewer replaces stale entries after a process restart.
- Main service, plugin runner, and web package versions are synchronized at `1.0.8`. Both published images support full and Lite deployments, and quick install defaults to `1.0.8`.
- To roll back the image version, pin `MUSICDL_IMAGE_TAG=1.0.7` and follow the README backup and migration guidance.

## 中文

- 正在处理的请求会在运行时重载期间继续使用原运行实例；关闭会等待重载完成，启动失败或取消时也会释放日志资源。
- 目录搜索会在阻塞操作结束前保留 broker 并发额度。音质探测会限制排队中的工作，Redis Stream Worker 也不再预取暂时无法处理的任务。
- 较长的企业微信搜索结果现在会分页，结果序号在各页保持不变。回复 `n` 或 `p` 翻页，回复 `/cancel` 清除当前选曲；已排队的下载会继续，重试回调仍绑定到原搜索和页面。
- Redis 重试预算现在按 consumer group 隔离，一个组不会消耗或清除另一个组的重试次数。死信记录会保留耗尽预算的组名。
- Telegram 客户端的初始化、连接、登出和关闭会按 profile 串行处理，避免并发操作争用会话文件。
- 管理设置会先完成校验，再修改运行状态；持久化失败时会恢复原状态。撤销会话也会清理 CSRF 状态，登录限流内存保持有界；服务日志页面会在进程重启后替换旧日志记录。
- 主服务、插件运行器和 Web 包版本统一为 `1.0.8`。两份已发布镜像均支持完整部署和 Lite 模式，快速安装默认使用 `1.0.8`。
- 如需回滚镜像版本，请固定 `MUSICDL_IMAGE_TAG=1.0.7`，并遵循 README 中的备份与迁移说明。
