# Phase 5 AI-assisted Ranking and Classification Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add optional, strictly validated OpenAI-compatible candidate re-ranking and four-category language advice while preserving deterministic behavior on every failure.

**Architecture:** A focused `musicdl.ai` package owns typed advice results, a bounded OpenAI-compatible HTTP client, and advisory orchestration. Existing source search remains the deterministic authority; Phase 4 language normalization remains the filesystem-category authority, and the AI package has no download capability.

**Tech Stack:** Python 3.12, Pydantic 2.12, pydantic-settings 2.15, httpx 0.28, asyncio, pytest 9.1.

**Spec:** `docs/superpowers/specs/2026-09-12-phase-5-ai-design.md`

## Global Constraints

- AI is disabled by default and cannot trigger, select, or execute a download.
- Accepted languages are exactly `华语`, `欧美`, `日韩`, and `未知`.
- Deterministic source normalization, deduplication, ordering, statuses, and fallback remain available without AI.
- Ranking sends at most `max_candidates` metadata records and never sends URLs, headers, credentials, sessions, or media bytes.
- Provider calls use one non-streaming `/chat/completions` request, `temperature: 0`, a JSON response-format request, and no retry.
- Provider bodies, prompts, base URLs, authorization values, API keys, and raw exception text never enter events.
- `asyncio.CancelledError` always propagates.
- Do not add the OpenAI SDK, persistence, provider-specific extensions, media analysis, admin UI, or automatic candidate selection.

## File Structure

- Create `src/musicdl/ai/__init__.py`: stable public exports only.
- Create `src/musicdl/ai/models.py`: immutable result/event contracts, client protocol, and stable `AIError`.
- Create `src/musicdl/ai/client.py`: one bounded OpenAI-compatible JSON completion call.
- Create `src/musicdl/ai/service.py`: ranking/language prompts, strict advice validation, event emission, and deterministic fallback.
- Modify `src/musicdl/config.py`: validated `AISettings` nested in `AppSettings`.
- Modify `src/musicdl/sources/search.py`: reusable deterministic `search_result_version()` helper.
- Modify `src/musicdl/sources/__init__.py`: export `search_result_version()`.
- Modify `pyproject.toml`: move the already pinned `httpx==0.28.1` from dev-only to runtime dependencies.
- Modify `.env.example`: commented AI configuration examples with no real secret.
- Modify `README.md`: accurately describe the optional advisory layer and fallback boundary.
- Create `tests/unit/test_ai_models.py`: configuration and immutable public contracts.
- Create `tests/unit/test_ai_client.py`: controlled HTTP endpoint contract and transport failures.
- Create `tests/unit/test_ai_ranking.py`: valid re-ranking, versioning, limits, and fallbacks.
- Create `tests/unit/test_ai_language.py`: language validation, fallbacks, cancellation, and redaction.
- Create `.planning/phases/05-ai-assistance/SUMMARY.md`: acceptance evidence only after verification.
