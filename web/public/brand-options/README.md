# musicdl brand options

These are six self-contained SVG concepts and three practical social-preview
PNGs created as selectable pairs for the musicdl project: a self-hosted,
multi-source music download service with a Chinese admin panel, Telegram
sources, WeCom workflows, and isolated JavaScript plugins.

The built-in image generator was attempted once for the first icon, but the
runtime returned the error: "400 model_not_found: unknown provider for model
gpt-image-2". The built-in tool was unavailable in this environment, so the
deliverables below are hand-authored vector concepts. No file here claims AI
generation.

## Option sets

| Set | Icon original | Banner original | Social preview PNG | Direction |
| --- | --- | --- | --- | --- |
| Cool aurora glass | icon-cool-aurora-glass.svg | banner-cool-aurora-glass.svg | social-preview-cool-aurora-glass.png | Deep navy, cyan and violet aurora, frosted glass, luminous music-download mark |
| Warm sunrise glass | icon-warm-sunrise-glass.svg | banner-warm-sunrise-glass.svg | social-preview-warm-sunrise-glass.png | Plum, coral and amber sunrise, warm glass, soft optimistic energy |
| Monochrome prism | icon-monochrome-prism.svg | banner-monochrome-prism.svg | social-preview-monochrome-prism.png | Graphite, white and silver geometric prism, restrained technical tone |

All icons are 1024x1024. The original banners are 1600x900 (16:9). The
social-preview PNGs are 1280x640 (2:1), exported with Sharp from a centered
1600x800 vertical crop so each mark stays fully in frame. Every pair shares
its palette, material language, and a combined musical-note plus downward-arrow
symbol. The icon mark is centered and intentionally simple for small rendering;
banners keep the left side relatively open for optional repository copy.

## Prompt set

The following prompts describe the intended generated-image directions and can
be reused if the image generator becomes available:

### Cool aurora glass

Use case: logo-brand. Asset type: project icon or GitHub banner. Create a
polished brand visual for musicdl, a self-hosted multi-source music download
service with Telegram and a Chinese admin panel. Use a cool aurora glass
direction: deep navy, electric cyan, teal, and violet; frosted translucent
glass; a clear musical note fused with a downward download arrow and a small
waveform; crisp, high contrast, no words, no watermark. For the icon use a
centered square composition that remains recognizable at 48px. For the 16:9
banner use a wide abstract composition with the mark on the right and generous
safe space on the left.

### Warm sunrise glass

Use case: logo-brand. Asset type: project icon or GitHub banner. Create a
polished brand visual for musicdl, a self-hosted multi-source music download
service with Telegram and a Chinese admin panel. Use a warm sunrise glass
direction: plum, coral, amber, peach, and cream; translucent sunrise glass; a
clear musical note fused with a downward download arrow and a small waveform;
crisp, high contrast, no words, no watermark. For the icon use a centered
square composition that remains recognizable at 48px. For the 16:9 banner use
a wide abstract composition with the mark on the right and generous safe space
on the left.

### Monochrome prism

Use case: logo-brand. Asset type: project icon or GitHub banner. Create a
polished brand visual for musicdl, a self-hosted multi-source music download
service with Telegram and a Chinese admin panel. Use a monochrome prism
direction: black, graphite, silver, and white; hard-edged translucent geometric
prism facets; a clear musical note fused with a downward download arrow; crisp
technical contrast, no words, no watermark. For the icon use a centered square
composition that remains recognizable at 48px. For the 16:9 banner use a wide
angular composition with the mark on the right and generous safe space on the
left.
